# ZONA v0.18 mobile fixes

- Hero artwork is now in normal flow below the text, so it cannot overlap the headline/content.
- Hero is compact and responsive on <=390px phones.
- Checkout steps use the full available mobile width.
- Delivery/payment cards are full-width, not squeezed into the old desktop content column.
- Inputs and textareas are larger/readable on mobile.
- Admin mobile header has a dedicated "На сайт" button.
- "На сайт" returns to the storefront without destroying the current admin login session.
- "Выйти" still performs a real admin logout.
