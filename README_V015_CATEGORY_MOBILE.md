# ZONA v0.15 — DIGIT Categories + Mobile Redesign

## Category sync
Every category received from DIGIT УЧЁТ is now automatically inserted into
the website `categories` table. Products remain assigned by their DIGIT category name.

Example:
DIGIT creates "Садовая техника"
→ next product sync creates the same category on ZONA
→ products in that category appear under it automatically.

Category cards on the home page now open the catalog already filtered by that category.
